# HotspotVPN DNS

Дополнение для выбора DNS клиентов точки доступа: Cloudflare, Google или свой IPv4. Версия 1.0.0, rootless iOS 15+.

| Пакет | Назначение и зависимости |
|---|---|
| `com.evgeniy.hotspotvpn` ≥ 1.0 | Оригинал: передача трафика через VPN, модуль Пункта управления. Требует CCSupport и библиотеку хуков. |
| `local.hotspotvpndns` | Наше дополнение: выбор DNS через DHCP. Требует оригинал, PreferenceLoader и библиотеку хуков. |

Оригинал в наш `.deb` не встроен и им не заменяется. VPN-приложение (например, Happ) устанавливается отдельно.

Сначала установите оригинальный HotspotVPN, затем наш `.deb` из Releases через менеджер пакетов. Если оригинала нет, автоматическая установка зависимости возможна только при наличии пакета в подключённых источниках. `dpkg -i` зависимости не скачивает.

Включите VPN и HotspotVPN в Пункте управления. Выберите DNS в **Настройки → HotspotVPN** и переподключите клиентов.

Добавлены панель настроек и hook `bootpd`: он заменяет существующую DHCP option 6 в OFFER/ACK, сохраняет размер пакета и пересчитывает UDP checksum. При первой установке включён Cloudflare `1.1.1.1`; обновления сохраняют настройки.

Проверено на iPhone 11 Pro Max / iOS 16.6.1 / Dopamine / ElleKit / Happ 6.0.0 по USB: DHCP, HTTPS, 8/8 UDP-проб DNS/STUN/NTP и 28 тестов парсера. UDP-ответы наблюдались после повтора через 1,3–1,5 с; причина задержки неизвестна. Wi-Fi и другие устройства не проверены. DoH/DoT, IPv6 и собственный DNS клиента не контролируются; kill switch отсутствует.

Сборка: Theos, совместимый Apple clang, iOS 16.5 SDK, подписанная arm64e PAC00 slice:

```sh
make clean package FINALPACKAGE=1 DEBUG=0
python3 tests/run.py
```

Нативная сборка: `HPD_SDK=/path/iPhoneOS16.5.sdk sh scripts/build-native.sh`; упаковка — `scripts/package.py --help`. SDK и инструменты в репозиторий не входят.

Удаление: `sudo dpkg -r local.hotspotvpndns`. Оригинал и настройки сохраняются.
